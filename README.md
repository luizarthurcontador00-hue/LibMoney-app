# LibMoney — download

Este repositório existe só para hospedar o arquivo de instalação do LibMoney.
O código-fonte fica em um repositório privado separado.

## Baixar

**[libmoney.apk](https://github.com/luizarthurcontador00-hue/LibMoney-app/raw/main/libmoney.apk)** — Android 6 ou superior

Abra esse link **no Chrome**. O navegador dentro do WhatsApp e do Instagram
não consegue concluir o download nem entregar o arquivo ao instalador do
Android: se você chegou por lá, toque nos três pontinhos e escolha
"Abrir no navegador".

Na primeira instalação o Android avisa que o app vem de fonte desconhecida e
pede para liberar o navegador em Configurações. Isso acontece com todo
aplicativo instalado fora da loja, e deixa de acontecer quando o LibMoney
estiver na Google Play.
